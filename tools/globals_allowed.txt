# The globals of the toolkit's packages and their class: tests/globals fails on one that is not here, on one listed that is gone,
# and on a class that is not what the code says. "<dir>/<file> <name> <class>  # why" (a procedure's @(static): "<proc>.<name>").
# The rule is docs/getting-started.md, "Where state lives". const: a table, written by the compiler or once before anything
# reads it, then only read (any thread). process: a resource of the process, one whatever the number of apps (locked, atomic,
# or bound to a thread the note names). thread: @(thread_local). test: a test's. There is no class for one window's or one
# app's state: it is a field of the struct that owns it (the Window, the render device or Renderer, ui.State).
# Rewrite it from the code (keeping the classes known): odin test tests/globals -define:GLOBALS_WRITE=true
