**`devtools`: a window driven over the Chrome DevTools Protocol**: `devtools.start_from_env(win)` (TOOLKIT_DEVTOOLS=<port>, 127.0.0.1 only) and `devtools.service` each frame. Input.dispatchMouseEvent / dispatchKeyEvent / insertText go into the window's queue (no mouse or keyboard of the machine, no focus needed), Page.captureScreenshot returns the presented frame as PNG, Accessibility.getFullAXTree the boxes a reader meets, and the Toolkit domain reads the box tree (getTree, find, click by name or text). `tools/cdp.mjs` drives it from the command line; docs/devtools.md. `ui.box_text` and `ui.box_current` read a box from outside a build.
