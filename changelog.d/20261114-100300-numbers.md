**Numbers as the language writes them**: `i18n.decimal`, `i18n.percent`, `i18n.decimal_marks` and `i18n.parse_decimal` write and read a number with the language's decimal mark and percent ("7,8 Go", "34 %" in French). The toolkit's numbers use them: number fields and sliders (a number typed with either mark is read), sizes, the settings' fields, the Diagnostics page, the preview's zoom.
