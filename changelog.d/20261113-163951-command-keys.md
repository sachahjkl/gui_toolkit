**A command has any number of keys**: `ui.Command.keys` is a `[]Chord`, not `[2]Chord` (Zoom in: Ctrl+=, Ctrl+Num +, Ctrl+Shift+=). Write `keys = {{.K, {.Ctrl}}}` for `keys = {{.K, {.Ctrl}}, {}}`. The first key that is not zero is the one shown. A key that the user rebinds or turns off is a table derived from the constant one, passed to every reader (docs/commands.md, "Keys the user changes").
