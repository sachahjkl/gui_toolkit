**A test session leaves nothing behind on Windows**: each font.State has its own DirectWrite factory (isolated): a shared one is the process's, and a face from memory has a key of its own each time it is loaded, so every State that ended left its faces in the factory's cache, about two megabytes a test session, until a package of a hundred and more sessions ended the process at about the hundred and twentieth, whichever test that was. And `render.destroy` lets the GPU finish what it was given first (Direct3D 11: an event query; WebGPU: a poll that waits): an offscreen frame is only flushed.
