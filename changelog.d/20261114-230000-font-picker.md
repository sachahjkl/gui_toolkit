**A font picker for the family settings**: the interface, monospace and reading font settings open a list of the system's families, each name drawn in its own family, with a search field that finds a family as it is typed. Default is at the top, the current family is selected, the monospace families are marked and come first for the monospace setting, and a choice is set at once. A program's own screen uses it with `ui.font_picker` (its families read once on the chores through a `ui.Font_Source`, `ui.font_system_source` for the system's; docs/font-picker.md). gt:font names the family of any face with `font.family_of` (an embedded or file face reads its `name` table), and `font.system_families` now returns `font.Family` values (`name`, `monospace`): read `.name` where it returned names.
