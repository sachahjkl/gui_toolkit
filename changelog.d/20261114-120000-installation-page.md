**An Installation page in every program's settings.** `prefs_page.Install` holds the install: the offer at a start (the setup's dialog), the user's answer (the hidden setting `install.choice`), and the Installation page at the end of the settings' sidebar, which says where the installed copy is, its version, whether this copy is the installed one, and each piece on the desktop: the menu's entry, Settings > Apps, the start with the session, the PATH and its console launcher; with Install, Repair, Upgrade and Uninstall. The palette finds the page ("install", "uninstall", "path"). `setup.page` draws it; `setup.Facts` has `autostart` and `on_path`; a `Page_Info` has `user` and `tags` (docs/prefs_page.md, docs/setup.md).
  - `setup.open_installed` no longer starts the installed copy: it says `Launched`, and the copy starts at the end (`prefs_page.install_launch`), once the program's single instance is released. Started at once, it found the old copy still running and handed itself over to it.
