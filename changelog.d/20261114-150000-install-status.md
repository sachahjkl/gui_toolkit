**`--status` in every program, beside `--install`, `--uninstall` and `--setup`.** It says what is installed (where, its version, the menu entry, the start with the session, the PATH) and whether the program runs (`running: true`), with the exit code 0 installed, 2 to repair, 1 not installed. `Setup_Options.running` gives the program's single-instance check; `setup.command_alone` says which commands run without a window (docs/setup.md).
