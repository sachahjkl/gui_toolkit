**A program's translations no longer change the toolkit's words, and the French reads right.** Each catalogue is a domain: a text of the toolkit's code is looked up in the toolkit's catalogue first, a program's text in the program's, then each in the other. A program that translates "Paste" or "Off" its own way no longer changes the field menu or the toolkit's settings.
  - French typography is set when the language loads: no line starts with ":", ";", "?", "!" or "%".
  - French: "Rechercher" everywhere (the settings' search, "Type to search", the update preference), "Synchronisation verticale" for Vsync, no program name after "de", clearer texts on the Diagnostics and Installation pages.
  - The settings' choices read well in English and French: RGB, BGR, sRGB and GDI in capitals; the filter precision says "16-bit floats" or "8 bits" instead of `Half` and `Unorm8`.
  - File types are named in the language in use (shared-mime-info's comments).
