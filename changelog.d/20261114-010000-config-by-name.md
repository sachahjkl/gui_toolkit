type: Changed

**Preferences read and set by name**: `config.get_bool`, `get_int`, `get_float` and `get_string` (by `Ref`) are gone; read with `bool_of`, `int_of`, `float_of`, `string_of` (by name). `set_bool`, `set_int`, `set_string` take the name instead of a `Ref` (`config.set_int(&p, config.ref_of(&p, "x"), 3)` becomes `config.set_int(&p, "x", 3)`), and the new `set_float` sets a Float without formatting it first. They return the `Set_Error` of `set_from_string`, which stays for text a user typed.
