**Export of the preferences**: `config.export_json`, `config.export_toml` and `config.export_ini` write the user's changes, or every value with `all = true`, as a flat JSON object, TOML tables per group, or INI sections per group. `config.export_own` writes our own format, which `config.load_file` reads back; it replaces `config.serialize_user`. Floats are written in the fewest digits that read back as the same value.
