type: Changed

**A setting of a State takes the State**: `set_window_button_names(min, max, restore, close)` → `set_window_button_names(&state, min, max, restore, close)`. `styled_face_of(&state, face, b, i)` is gone: `styled_face(face, b, i)` reads the State in use (outside a build, `ui.use(&state)` first).
