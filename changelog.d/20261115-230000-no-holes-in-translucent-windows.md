**No holes where the window showed what is behind it**: a translucent window that blends in linear light (every window on Windows with DirectComposition, and a Linux window composited with its alpha) no longer shows the desktop or another window through a few pixels: around inline code in a table, along the fading edges of a list, under the text. What is drawn is now kept within its normal range in every frame format, so these windows show exactly what an opaque window shows. `render.init_offscreen` takes `half_float` to draw a frame in that format, `render.read_pixels_float` reads its values as they are stored, `render.frame_is_half` says which format a frame is in, and the test sessions take `half_float` with `session.capture_float` and `session.out_of_range`. The partial redraw check (`render.damage.verify`) now also compares frames stored in half floats.
