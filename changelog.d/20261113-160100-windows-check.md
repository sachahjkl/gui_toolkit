**`toolbox.odin_check`, `toolbox.check_env`**: `odin check` of a package for another system, Windows from Linux too (an Odin root whose wgpu has an empty Windows library). `tk ci` on Linux checks every package of `src/` for Windows, and `run_tests -check:windows_amd64` checks every test package and program with its own defines: Windows code that does not compile fails the Linux job.
