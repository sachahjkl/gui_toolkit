type: Changed

**Views across several windows, an icon per opening, the next field focused**: `host.view_windows(&app.shared)` is now one backend for every window of a program, set once (it took one owner window: a program of several windows set it again in each window's build); each view's window is made after the frames of the window that owns the view. `ui.views_commands(vs, allocator, owner)` and `ui.views_commands_update(vc, vs, owner)` list only the moves of the views a window owns, for that window's palette. `ui.view_icon(v, icon, icon_font)` gives a view an icon per opening, as `view_title` gives a title. `ui.focus_next_field()` gives the keyboard to the next field built (a `number`'s value field included), so a view focuses its field on its first build without knowing a widget's inner keys. Fixed: a zone's tab that is not shown was built a second time, over its zone, which kept two panels shown and took the presses on the tabs.
