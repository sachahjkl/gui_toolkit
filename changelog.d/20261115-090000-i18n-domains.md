**A program's translations no longer change the toolkit's words.** Each catalogue is a domain: a text of the toolkit's code is looked up in the toolkit's catalogue first, a program's text in the program's (then each in the other). A program that says "Paste" its own way no longer changes the field menu, nor "Off" the toolkit's settings. French typography is set when the language loads: no line starts with ":", ";", "?", "!" or "%" any more.
