**The selection of several rows, the same in every list (`ui.Item_Selection`)**: a list, a virtual list or a table with `multi` selects as a file manager does. A click selects a row alone, Ctrl+click toggles it, Shift+click selects the range from the anchor (a second one replaces it), and Ctrl+Shift+click adds the range. Shift with the arrow keys, Page Up, Page Down, Home and End extends; Ctrl with them moves the active row only. Ctrl+Space toggles the active row, Ctrl+A selects all, and Escape clears. A program's own grid gets the same rules from `item_selection_click`, `item_selection_move` and `item_selection_key`. The marks (`list_is_marked`, `list_mark_count`, `marks`) are replaced by `list_is_selected`, `list_selected_count`, `list_selected_ids` and `selected_changed`. A selection is always explicit: one row clicked is in it, and the active row can be outside it. Screen readers hear a multi list as multiselectable.
