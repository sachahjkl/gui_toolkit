**Every program gets the same Windows basics from its `Project`, with no code of its own**: gt:toolbox's `build_native` (through the new `build_windows`) writes the program's resource from the Project, and `odin_command` links it. The resource has the icon (`icon`, by default `assets/<name>.ico`), the version and names (`title`, `description`, `publisher`, `copyright`: what Properties and Task Manager show) and a manifest (per-monitor DPI v2, UTF-8 code page, long paths, common controls 6). The same build makes the console launcher `<name>.com`: the program embeds it, `desktop.install` writes it with the PATH entry, and the Windows release archive has it beside the `.exe`. Every window gets the program's icon at the large and small sizes.
  - The AppUserModelID is derived, never written: `platform.app_user_model_id(publisher, name)` joins PascalCase words by a dot ("Froment Software" and "opencode native" give `FromentSoftware.OpencodeNative`). The build gets `GT_AUMID` from the Project's publisher and title (`project_aumid`; none without a publisher), and gt:desktop's `Identity.aumid` is derived from its vendor and name when empty (`identity_aumid`), so the windows and the shortcuts group in the taskbar.
  - A program deletes its `res/*.rc`, its manifest, its `#load` of the launcher and its launcher mark. `Launcher.out` → `launcher_path(p)`, `Launcher.mark` → `launcher_mark(p)`; `version_header` and `write_version_header` are removed.
