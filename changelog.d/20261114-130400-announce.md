type: Changed

**`announce` is the one call that says something**: `toast`, `toast_action` and `toast_titled` are gone. `announce(&announcer, kind, title, body, action, user)` obeys the person's Messages setting; a failure is always said; a title and a body are a titled toast (no more "title: body" on one line); a message with an `action` is a toast of the window whatever the setting. `prefs_page.messages_mode` → `prefs_page.announce_mode` (the setting keeps its name, `general.messages`).
  - `ui.toast(kind, fmt, args)` → `ui.announce(&app.announcer, kind, fmt.tprintf(fmt, args))`
  - `ui.toast_titled(kind, title, body)` → `ui.announce(&app.announcer, kind, title, body)`
  - `ui.toast_action(kind, f, user, fmt, args)` → `ui.announce(&app.announcer, kind, fmt.tprintf(fmt, args), action = f, user = user)`
