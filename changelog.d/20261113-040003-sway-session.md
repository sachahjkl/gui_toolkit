**`toolbox.sway_start`**: a sway desktop nobody sees, for a tool's live tests and pictures on Linux. It has its own runtime directory and sockets, no session bus, and, when asked, its own configuration, data, state and cache folders. Its programs and sway stop with all they started, also when a signal ends the tool (`toolbox.guard_groups`). `tk desktop_tests wayland` runs in it.
