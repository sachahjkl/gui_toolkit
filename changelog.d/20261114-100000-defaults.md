type: Changed

**Standard settings whose defaults need no override**: a program that set them through `Standard_Defaults.values` or followed the system itself drops that code.
  - `appearance.text.subpixel` is `auto` by default: text is smoothed per colour stripe as the system smooths its own (ClearType and its order on Windows, fontconfig on Linux, grey on macOS), read once at the start by `prefs_page.standard_register`. `off`, `rgb` and `bgr` stay. A program that called `font.system_subpixel_text` while the setting was at its default drops that call.
  - `appearance.text.grid_fit`'s `default` is `auto` ("Auto", "On", "Off"): `font.Grid_Fit.Default` → `font.Grid_Fit.Auto`. A settings file that holds `default` falls back to `auto`.
  - `rendering.partial_redraw` is on: each frame redraws only what changed; a frame that cannot (a backdrop, a plane) is drawn whole.
  - `scrolling.smooth` is `on`: a notch of the wheel glides even when the system asks for fewer animations. `follow` stays a choice.
