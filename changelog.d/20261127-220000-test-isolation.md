**A test never reaches the person's desktop, bus or graphics card**: on Linux every test process, however it was started, and every program a tool of the toolkit runs (program sessions, `tk` screenshots, the timeline test) has its environment isolated before its main (`base.isolated_env`): no display but a server the test started itself (`GT_TEST_DISPLAY`), a session bus where nothing answers unless the test has its own (`GT_TEST_BUS`), Vulkan on Mesa's lavapipe alone with the implicit layers off, Mesa's EGL vendor alone, no VA-API driver. A test started by hand from a desktop's shell opened its windows on that desktop, spoke on its bus and could load NVIDIA's EGL driver. `base.software_vulkan_driver` (moved from `toolbox`) and `base.mesa_egl_vendor` find Mesa's drivers.
