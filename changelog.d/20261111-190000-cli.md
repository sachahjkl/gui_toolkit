**`cli`: a program's command line from one table of its options**: `cli.check` answers `--help` with the help made from the table and `--version` with the version, and refuses an option the table does not have (why, then the help; exit code 2), so a typo or a guess no longer starts the program as if nothing was said. Options take a value (`--session=<id>`), an optional one (`--settings[=<n>]`), one in the next argument (`--pref <name=value>`), or are hidden (what tools pass).
