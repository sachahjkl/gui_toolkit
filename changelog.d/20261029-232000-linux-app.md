**Linux: an application builds and draws.** Found by building opencode native for Linux:
- the WebGPU backend defaulted to Direct3D 12 on every system: Vulkan off Windows (`TOOLKIT_WGPU_BACKEND`);
- a translucent window asked for a half-float surface that Vulkan on X11 / Wayland does not offer (BGRA8 only): the
  surface's formats are checked, 8 bits a channel otherwise;
- the text renderer defaulted to the atlas, which nothing fills off Windows (no bitmap rasterizer): Slug there
  (`FONT_TEXT_RENDERER`);
- `-define:FONT_NATIVE_LINK=false` linked `kernel32.lib` as its stand-in everywhere: libc off Windows;
- `-vet` failed on the Linux code (dbus casts, unused loop variables in the X11 backend, imports used on Windows only).

`tools/fetch_wgpu.sh`: wgpu-native's Linux static library, pinned by SHA-256, into Odin's `vendor/wgpu/lib` (Odin's Linux
release does not ship it).
