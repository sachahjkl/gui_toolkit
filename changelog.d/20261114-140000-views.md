type: Changed

**Views replace modal dialogs**: a dialog is now a view, a build procedure and its data declared once by an id (`ui.view_register`, `ui.view_open`, `ui.view_close`, `ui.view_ended`, `ui.view_end`). Every window's `ui.State` has its views, with nothing to set up (`ui.state_views(&state)`, or `ui.views()` for the window being built); a program that keeps the user's choices in a file, or whose windows share their views, owns one `ui.Views`, reads its file with `ui.views_init(&vs, {path = ...})`, gives it to each window with `ui.set_views(&state, &vs)` and ends it with `ui.views_destroy`. The program opens a view and reads its answer in a later build; the toolkit builds it at the end of the window's build, draws its header (icon, title, a small Detach icon, the close cross) and remembers per id the dialog's size, its presentation and whether it was open at the last quit (`view_was_open`). Escape, Ctrl+W, the close cross and a press outside end it with `VIEW_CANCELLED`. A dialog still shows only once its layout has settled, and fades in. Migration: `if ui.modal(id, &open, {width_em, size = &size}) { body }` becomes `ui.view_register(ui.views(), id, build, {title, width_em, resizable = true})` and `ui.view_open(ui.views(), id, &data)`, the body in `build :: proc(v: ^ui.View, data: ^T)`; `ui.dialog_header` goes (`View_Options.title`, `icon`, `ui.view_title`, `ui.view_header_tools`); `open = false` in the body is `ui.view_end(v, code)`; `ui.modal`, `Modal_Options`, `ui.dialog_header`, `Dialog_Header_Options` and `ui.modal_corner` are no longer public.
