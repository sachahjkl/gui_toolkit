**A menu is as wide as its widest row**: a label next to a long shortcut ("Show as QR code", Ctrl+Shift+Q) is no longer cut. The width a caller gives (`ctx_menu`, `menu_nested`, a drop-down's list) is a minimum, a wider `text_pad` widens the menu, and only a menu wider than the window cuts a label, whose row then shows it whole as a tooltip; a line the command palette cuts does the same.
