**A lazy column, `ui.lazy_begin` / `ui.lazy_item`**: inside a scroll box only the items near the view are built, the others stand as one space of the height they had when last built (5000 wrapped paragraphs: 4 ms a frame instead of 1200). Everything is built when the width changes or with `lazy_begin(all = true)` (find in page). Like `row()`, the item is the block of the `if`: a column whose items all close empty (`if !lazy_item(...) { continue }`) is warned of.
