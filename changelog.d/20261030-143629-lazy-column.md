**A lazy column, `ui.lazy_begin` / `ui.lazy_item`**: inside a scroll box only the items near the view are built, the others stand as one space of the height they had when last built (5000 wrapped paragraphs: 3 ms a frame instead of 100, a first frame of 12 ms instead of 1.4 s). An item never built stands as the mean height; one built at another width keeps its old height until it comes near the view; the view stays on the item it showed when heights change (after the layout, in the same frame). `lazy_begin(all = true)` builds every item (find in page). Like `row()`, the item is the block of the `if`: a column whose items all close empty (`if !lazy_item(...) { continue }`) is warned of.
