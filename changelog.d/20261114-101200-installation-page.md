**An Installation page in every program's settings** (docs/prefs_page.md, docs/setup.md). `prefs_page.Install` holds the install: the offer at a start (the setup's dialog), the user's answer (the hidden setting `install.choice`) and the Installation page at the end of the settings' sidebar. The page says where the installed copy is, its version, whether this copy is the installed one, and each piece on the desktop: the menu's entry, Settings > Apps, the start with the session, the PATH and its console launcher. It offers Install, Repair, Upgrade and Uninstall; the palette finds it ("install", "uninstall", "path"). `setup.page` draws it; `setup.Facts` has `autostart` and `on_path`; a `Page_Info` has `user` and `tags`.
  - An uninstall from the page answers "standalone": the next start offers no install. The offer obeys `install.choice`'s value for the run (the command line's over the user's file), as `prefs_page.install_choice` gives it; `prefs_page.choice_after` says what each event leaves.
  - `setup.open_installed` no longer starts the installed copy: it says `Launched`, and the copy starts at the end (`prefs_page.install_launch`), once the program's single instance is released. Started at once, it found the old copy still running and handed itself over to it.
