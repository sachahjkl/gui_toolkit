type: Changed

**A release is checked against a target**: `update.check_release(p, manifest, signature, platform, channel, current, announced)` becomes `check_release(p, manifest, signature, {platform = …, channel = …, current = …, announced = …})` (an `update.Release_Target`), and `update.verify(p, manifest, signature, platform, channel)` becomes `verify(p, manifest, signature, {platform = …, channel = …})`. `update.manifest_of(p, data, version, platform, channel, published)` becomes `manifest_of(p, data, {version = …, platform = …, channel = …, published = …})`.
