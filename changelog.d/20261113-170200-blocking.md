**`base.blocking`**: in a debug build (`TOOLKIT_BLOCKING_CHECK`), a procedure of the toolkit that waits on the system (a file read or written, a dialog, a URL or a file opened, a notification, the clipboard read at once, the preferences saved, a theme icon) called on a thread that builds an interface is said on the standard error, once per call site of the program, and counted (`base.blocking_count`): what can freeze a window is found before a person meets it.
