**The toolkit in French**: with the Language setting in French, the toolkit's own words are French: the field menu (Couper, Copier, Coller, Tout sélectionner…), dialogs and their buttons, the command palette and the key sheet, the dock's and the tables' menus, key names, the settings page and every standard setting (titles, descriptions, choices, groups), Export and Import, the update and shortcut lines, licence and install messages, the Setup dialog, file dialogs' filters, ages, durations and dates. The texts a program declares with `i18n.later` (its settings, commands, flowgraph nodes, table columns) show in the user's language where the toolkit shows them, and the settings search finds a setting by its translated words and by its English.
