**`crash_bar`: the last run's crash, said the same way in every program** (docs/crash_bar.md). At the next start, a bar across the window says what happened (a crash and its reason, a session ended by the system, an exit) in a sentence that wraps, with Open the report, Copy, Report on GitHub (a new issue of the program's repository with the report in it) and a cross that dismisses it.
