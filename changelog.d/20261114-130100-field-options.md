**`line_edit` and `text_edit` take their options in a struct**: `line_edit(id, f, o: Line_Edit_Options)` and `text_edit(id, a, o: Text_Edit_Options)`. A line edit's `kind` (`Line_Edit_Kind`: `.Plain`, `.Secret`, `.Read_Only`) replaces `secret` and `read_only`; `reveal` works with `.Secret`; `clearable` shows no cross on a read-only field; `own_menu = true` replaces `menu = false`. `edit_menu(key, target, owner, kind)` and `line_edit_key(f, owner, key, mods, kind)` take the same `kind` in place of their two booleans. How a program moves:
  - `line_edit(id, &f, "Name")` → `line_edit(id, &f, {placeholder = "Name"})`.
  - `line_edit(id, &f, secret = true, reveal = &shown)` → `line_edit(id, &f, {kind = .Secret, reveal = &shown})`; `read_only = true` → `{kind = .Read_Only}`; `clearable = true` → `{clearable = true}`; `menu = false` → `{own_menu = true}`.
  - `text_edit(id, &a, "Notes", wrap = true, max_lines = 4)` → `text_edit(id, &a, {placeholder = "Notes", wrap = true, max_lines = 4})`; the same for `line_numbers`, `tab_indents`, `auto_height`, `min_lines`, `highlight`; `menu = false` → `{own_menu = true}`.
  - `edit_menu(key, target, owner, secret = true)` → `edit_menu(key, target, owner, .Secret)`; `read_only = true` → `.Read_Only`.
