type: Changed

**Every program gets the same Windows basics from its `Project`, with no code of its own**: gt:toolbox's `build_native` (through the new `build_windows`) writes the program's resource from the Project, and `odin_command` links it. The resource has its icon (`icon`, by default `assets/<name>.ico`), its version and names (`title`, `description`, `publisher`, `copyright`: what Properties and Task Manager show), and a manifest (per-monitor DPI v2, UTF-8 code page, long paths, common controls 6). The same build makes the console launcher `<name>.com` for every program. The program embeds it, `desktop.install` writes it with the PATH entry, and the Windows release archive has it beside the `.exe`. Every window gets the program's icon at the large and small sizes, and the windows group under `Project.aumid` in the taskbar. `Launcher.out` and `Launcher.mark` are gone (`launcher_path`, `launcher_mark`), and so are `version_header` and `write_version_header`. A program deletes its `res/*.rc`, its manifest, its `#load` of the launcher and its `launcher_mark`.
