**One dialog call, its sizes in ems**: `modal(id, &open, Modal_Options)` replaces `modal` and `modal_sized`, with `width_em`, `height_em` (0: as tall as what is in it), `min_width_em`, `min_height_em`, `size` (nil: not resizable; else what the person chose, in ems) and `top` (a fraction of the window's height; nil: centered). A dialog with no `top` is centered, a confirmation and a prompt too (they sat at 0.28 of the window's height).
  - `modal(id, w, &open, y)` → `modal(id, &open, {width_em = w / em, top = y})`
  - `modal_sized(id, preferred, &size, &open, min, top = t)` → `modal(id, &open, {width_em = preferred.x / em, height_em = preferred.y / em, min_width_em = min.x / em, min_height_em = min.y / em, size = &size, top = t})`; a `size` kept is in ems now, not logical pixels (the palette's `Command_Palette.size`, the Setup dialog's `Dialog.size` too)
  - `CONFIRM_WIDTH_EM` → `DIALOG_WIDTH_EM`, the width of a dialog that gives none
